🔬 How Disease Detection Works

0

Color Heuristic (Fast Gate)

Checks if the image contains plant-like colors — green, yellow, brown, or red pixels typical of leaves.

1

MobileNetV2 Semantic Check

Pre-trained on ImageNet 1000 classes — identifies plant/vegetable/flower content. Image passes if Stage 0 OR Stage 1 succeeds.

2

CNN Disease Classifier

Our custom EfficientNet/CNN trained on 87K PlantVillage images predicts disease with confidence score.

🧠 Model Architecture

The disease classifier uses a deep Convolutional Neural Network:

  • Input: 128×128×3 RGB images
  • 4 Conv blocks with BatchNormalization
  • Data augmentation (flip, rotate, zoom)
  • Global Average Pooling → Dense layers
  • 38-class Softmax output
  • Trained with Adam optimizer, EarlyStopping
  • Achieves >90% validation accuracy

Dataset: PlantVillage (Penn State University) — 87,000 leaf images across 38 disease categories.

🛠️ Technology Stack

  • Backend: Python 3.11, Flask 3.x
  • AI/ML: TensorFlow 2.x, Keras, MobileNetV2
  • Database: SQLite (via Python sqlite3)
  • Image Processing: Pillow, NumPy, OpenCV
  • Weather API: Open-Meteo (free, no key needed)
  • Frontend: Vanilla HTML/CSS/JS, Playfair Display + DM Sans
  • Dataset: PlantVillage (Penn State, Kaggle)

🌤️ Weather Advisory

The spray advisory uses real-time weather from Open-Meteo — a free, open-source weather API with no registration required.

Factors evaluated using IPM (Integrated Pest Management) guidelines:

  • 🌡️ Temperature (ideal 15–30°C)
  • 💧 Humidity (ideal 40–90%)
  • 🌬️ Wind speed (<15 km/h = safe)
  • 🌧️ Precipitation (any rain = postpone)
